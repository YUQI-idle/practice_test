# 수학 스텝업

Flask와 SQLite로 만든 단계별 수학 학습 프로그램입니다. 고등수학 기초에서 시작해 미적분과 공학수학까지 이어집니다.

## 현재 학습 계획

- 현재 수준: 고등수학 기초부터
- 목표: 공학수학 독학, AI/머신러닝 수학 기초
- 학습 시간: 1시간
- 저장 항목: 학습 프로필, 단계별 진도, 퀴즈 점수

## 실행 방법

프로젝트 폴더에서 다음을 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 가상환경이 아직 없다면 먼저 `py -m venv .venv`를 실행합니다.

## 학습 단계

1. 대수와 함수
2. 지수와 로그
3. 삼각함수
4. 극한과 연속
5. 미분의 정의와 기본 공식
6. 미분의 응용
7. 적분의 기본
8. 적분의 응용
9. 수열과 급수
10. 벡터와 선형대수
11. 다변수 미적분
12. 벡터 미적분
13. 미분방정식
14. 라플라스 변환
15. 푸리에 급수와 변환
16. 복소수와 복소함수

각 단계에서 개념을 읽고 확인 문제를 풀 수 있습니다. 정답 제출 시 퀴즈 시도와 진도를 저장합니다.

## 데이터베이스

첫 실행 시 프로젝트 폴더에 `learning.db` SQLite 파일과 테이블이 자동으로 생성됩니다. DB에는 학습 프로필, 강의 내용, 완료 여부와 퀴즈 답안 기록이 저장됩니다. 이 파일은 `.gitignore`에 포함되어 GitHub에 올라가지 않습니다.

다른 위치의 DB 파일을 사용하려면 `MATH_APP_DB` 환경 변수를 지정합니다.

```powershell
$env:MATH_APP_DB = "C:\경로\learning.db"
.\.venv\Scripts\python.exe app.py
```

현재 프로젝트는 학습 진도와 퀴즈를 확인하기 위한 실습용 앱입니다. 공개 배포 시에는 사용자 계정과 개인별 데이터 분리, 운영용 웹 서버 설정을 추가해야 합니다.
